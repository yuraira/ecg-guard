# ECG Guard 웹 데모

## 목적

웹 데모는 동결된 baseline v1의 단일 기록 추론 결과를 심사와 연구 재현을 위해
보여준다. 실제 환자의 진단, 선별, 치료 또는 응급 판단을 지원하는 서비스가
아니다.

## 입력 계약

- WFDB `.hea` 파일 1개와 헤더가 참조하는 `.dat` 파일
- 100Hz, 10초, 유도당 1,000표본
- 표준 12유도 순서: I, II, III, aVR, aVL, aVF, V1~V6
- 진폭 단위: mV
- 전체 업로드 제한: 50MB

업로드 이름의 경로 문자를 거부하고, 헤더가 선언한 크기·유도 순서·데이터 파일
참조를 확인한다. 파일은 요청 처리 중 생성한 임시 디렉터리에만 저장하고 분석이
끝나면 삭제한다. 분석된 파형과 결과는 현재 세션 메모리에만 유지하며 사용자는
화면의 삭제 버튼으로 이를 제거할 수 있다. 업로드 원래 파일명은 결과에 남기지
않는다.

실제 환자 파일은 허용하지 않는다. 업로드 전에 공개되었거나 적절하게 비식별
처리된 연구 데이터임을 확인해야 하며 상세 정책은
[`DATA_HANDLING_POLICY.md`](../DATA_HANDLING_POLICY.md)를 따른다.

## 실행

```powershell
$env:ECG_GUARD_CHECKPOINT="outputs/baseline/best_model.pt"
$env:ECG_GUARD_DEMO_RECORD="data/raw/ptb-xl/records100/00000/00001_lr"
.\.venv\Scripts\ecg-guard-web.exe --server.headless true
```

`ECG_GUARD_DEMO_RECORD`는 선택 사항이다. 공개 배포에서는 서버의 임의 경로를
입력받지 않으며, 운영자가 사전에 지정한 비식별 공개 샘플만 노출한다.

## 화면에서 확인할 내용

1. 체크포인트 SHA-256과 모델 버전
2. 12유도 ECG 파형
3. 클래스별 보정 확률과 검증 데이터에서 잠근 임계값
4. 기술 품질 상태와 구체적인 검토 항목
5. 결정 경계 불확실성과 판단 보류 여부
6. 연구·교육용 사용 범위와 알려진 한계

## 공개 배포 전 조건

- 체크포인트를 승인 없이 내려받을 수 있는 공개 저장소에 배포
- PTB-XL 출처와 CC BY 4.0 고지 유지
- 업로드 파일 비저장 정책과 접근 로그 정책 문서화
- HTTPS, 요청 크기 제한, 오류 로그의 원문 파형 제외 확인
- 실제 배포 사업자, 접속 로그 항목·보유 기간과 국외 이전 여부 문서화
- 공개·비식별 연구 데이터 확인 절차와 세션 결과 삭제 기능 유지
- 외부 임상 검증이 없다는 고지를 첫 화면과 결과 화면에 유지
