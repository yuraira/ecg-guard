# ECG Guard Baseline v1 모델 카드

## 모델 개요

- 상태: **동결됨**
- 동결일: 2026-07-27
- 모델: residual 1D CNN
- 파라미터: 1,958,533개
- 입력: 100 Hz, 10초, 표준 12유도 ECG `(12, 1000)`
- 출력: NORM, MI, STTC, CD, HYP 다중 라벨 확률
- 체크포인트 SHA-256:
  `44A8ECC96F1AC084DB2EF6921BF8E438C1130DA6BE140D7FC3AC7FE3ECFA2EAD`

## 배포 상태

체크포인트의 공개 패키지는 모델 카드, 잠긴 추론 프로토콜, 체크섬, SBOM,
Apache-2.0 라이선스 및 PTB-XL 고지와 함께
[`baseline-v1` GitHub Release](https://github.com/yuraira/ecg-guard/releases/tag/baseline-v1)에
게시했다. 인증 없는 다운로드와 SHA-256 검증을 완료했으며 준비·재검증 절차는
`docs/model_release.md`에 기록한다.

## 허용된 사용

- 공개 ECG 데이터의 연구·교육용 분석
- 다중 라벨 분류, 확률 보정, 오류 및 신뢰도 분석 예제
- 의료 AI 소프트웨어의 재현성·안전성 설계 학습

## 허용되지 않는 사용

- 실제 환자의 진단, 선별, 치료 또는 응급 의사결정
- 의료인의 판단을 대체하는 자동 판정
- 추가적인 임상 검증 없이 의료기기 또는 상용 서비스에 탑재
- 입력 형식·유도 순서·단위가 다른 ECG에 대한 무검증 적용

## 학습 데이터와 라벨

- PTB-XL 1.0.3의 100 Hz 파형
- 공식 `strat_fold` 1~8 학습, 9 검증, 10 시험
- 다섯 진단 상위군 중 하나 이상을 가진 21,388건 사용
- 학습 17,084건, 검증 2,146건, 시험 2,158건
- 환자 중복 분할 없음
- 학습 코호트만으로 전역 평균·표준편차 계산

PTB-XL의 SCP 문구를 다섯 진단 상위군으로 집계한 연구용 라벨이며 개별
환자에 대한 확정적 임상 진단으로 해석하지 않습니다.

## 동결된 성능

시험 fold 10의 2,158건, 1,877명에서:

- macro AUROC: 0.91627
- 95% patient-cluster bootstrap 구간: 0.90871~0.92378
- macro average precision: 0.81057
- 95% 구간: 0.79269~0.82625
- macro 민감도: 0.82693
- macro 특이도: 0.85176
- macro Brier score: 0.08652

Temperature와 클래스별 임계값은 검증 fold 9에서 결정했습니다. 상세 결과는
`docs/experiments/baseline_v1.md`와 `docs/evaluation_protocol_v1.md`에
기록합니다.

## 알려진 한계와 위험

- 단일 데이터셋, 단일 학습 seed 결과입니다.
- 외부 병원, 장비, 인종·지역 집단과 전향적 임상 데이터에서 검증하지 않았습니다.
- HYP의 시험 precision은 0.39439로 false positive가 많습니다.
- 단일 모델의 보정 확률은 epistemic uncertainty를 충분히 표현하지 못합니다.
- artifact 주석은 희소하며 주석 부재가 고품질 신호를 보장하지 않습니다.
- 연령·성별 하위집단 결과는 기술적 탐색 분석이며 공정성의 증거가 아닙니다.
- bootstrap 구간은 고정된 모델과 보정 파라미터에 조건부이며 학습 seed 변동을
  포함하지 않습니다.
- 모델이 내는 확률은 질병의 임상적 사전확률이나 환자별 위험도가 아닙니다.

## 시험 데이터 재사용 정책

Baseline v1의 시험 결과는 이미 확인했습니다. 이후 오류 분석과 신호 품질 기능은
v1의 사후 기술 분석으로 구분합니다. 이 결과를 바탕으로 분류 모델이나 임계값을
변경한 경우 동일한 fold 10 재평가 값을 새로운 “미접촉 최종 성능”으로 주장하지
않습니다. 개선 모델은 별도 외부 데이터 또는 사전에 고정한 새 평가 설계가
필요합니다.

## 책임 있는 출력

사용자 화면에는 다음을 함께 표시해야 합니다.

- 연구용 결과이며 의료 진단이 아니라는 고지
- 입력 신호 품질 및 모델 신뢰도
- 클래스별 확률과 사용한 임계값
- 낮은 품질·낮은 신뢰도에서 판정 보류 또는 재검토 권고
- 모델 버전과 입력 요구사항

이 계약은 `src/ecg_guard/resources/baseline_v1_inference.json`,
`ecg_guard.inference.predict_record`와 `ecg_guard.web.app`에 구현했다.
CLI와 웹 데모 모두 추론 시 체크포인트 SHA-256을 확인하며, 클래스별 보정
확률·임계값과 기술 품질·불확실성 검토 사유를 분리해 반환한다.

## 신뢰도 보조 분석

학습 파형 분포에서 극단적인 SQI를 표시하는 기술 품질 점수를 추가했다.
Artifact 주석과의 AUROC는 검증 0.526, 시험 0.557이었고 모델의 any-label
오류 탐지 AUROC는 시험 0.504였다. 따라서 자동 입력 폐기나 모델 신뢰도
추정에 사용하지 않고 별도의 기술 검토 사유로만 표시한다.

단일 모델의 결정 경계 근접도 uncertainty proxy는 시험 any-label 오류 탐지
AUROC 0.757이었다. 검증에서 정한 80% 목표 coverage cutoff를 시험에 적용한
실제 coverage는 77.4%였으며 Hamming 오류율은 전체 0.1504에서 0.1270,
any-label 오류율은 0.4893에서 0.4201로 감소했다. 이는 선택된 하위집단의
trade-off이지 모델 자체 성능 향상이나 임상적 안전성의 증거가 아니다.
