# ECG Guard 3분 시연영상 대본

목표 길이는 2분 50초이며 화면 전환을 포함해 3분을 넘지 않도록 한다. 실제 환자
데이터를 사용하지 않고 공개 서비스의 합성 샘플만 시연한다.

## 촬영 전 준비

- 촬영 5분 전에 `https://ecg-guard.onrender.com`을 열어 무료 인스턴스를 깨운다.
- 해상도는 1920×1080, 브라우저 배율은 90~100%로 설정한다.
- 공개 데모, GitHub 저장소, 성능 그래프, `baseline-v1` Release와 CI 화면을 미리 연다.
- 알림, 계정 정보와 불필요한 브라우저 탭을 닫는다.

## 표현상 주의사항

- 기술 품질 100점은 모델 정확도가 아니라 합성 입력의 기술적 품질 점수다.
- 성능 수치는 PTB-XL 내부 시험 세트 결과이며 임상 성능으로 표현하지 않는다.
- “질병을 진단한다” 대신 “연구용 진단 상위군 분류 결과를 제공한다”고 말한다.
