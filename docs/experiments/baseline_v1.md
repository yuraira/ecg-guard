# Baseline v1 실험 기록

실행일: 2026-07-27
목적: ECG Guard 데이터·학습 파이프라인 검증 및 후속 신뢰도 평가의 기준 모델 확정

## 데이터와 코호트

- 데이터: PTB-XL 1.0.3, 100 Hz 12유도, 기록당 10초
- 라벨: NORM, MI, STTC, CD, HYP 다중 라벨
- 공식 분할: `strat_fold` 1~8 학습, 9 검증, 10 시험
- 전체 메타데이터: 21,799건
- 현재 다섯 라벨 중 하나 이상을 가진 모델링 코호트: 21,388건
- 학습: 17,084건
- 검증: 2,146건
- 보류된 시험: 2,158건
- 환자 단위 분할 간 중복: 0명

다섯 진단 상위군이 없는 411건은 메타데이터 감사 대상에는 보존했지만 현재
다섯 라벨 분류에서는 제외했다. NORM과 다른 상위군이 함께 있는 445건은
원자료의 다중 라벨을 임의로 수정하지 않았다.

## 전처리와 모델

- 파형 형태: `(12, 1000)`
- 학습 코호트 전체 값을 이용한 전역 scalar 표준화
  - 평균: -0.0008252534045780403
  - 표준편차: 0.23222258095421358
  - 통계 계산 표본 수: 205,008,000
- residual 1D CNN
- 파라미터: 1,958,533개
- 출력: 다섯 개 독립 logit
- 손실: `BCEWithLogitsLoss`
- 최적화: AdamW, 학습률 0.001, weight decay 0.0001
- batch size: 128
- seed: 42
- 최대 15 epoch, patience 4
- 모델 선택 기준: 검증 macro AUROC

정규화 통계 계산, 학습, 검증, 모델 선택에는 시험 폴드 파형이나 라벨을
사용하지 않았다.

## 재현 명령

```powershell
.\.venv\Scripts\python.exe -m ecg_guard.training.train_baseline `
  --data-dir .\data\raw\ptb-xl `
  --output-dir .\outputs\baseline `
  --epochs 15 `
  --batch-size 128 `
  --num-workers 4
```

동일 seed와 512/256건 제한 표본의 1 epoch GPU 스모크 학습을 두 번
실행했을 때 `history.json` SHA-256이 모두
`376D939C91765736C9D186CC6887276DB2F0BE75D3B41B1B02DF92C2E934F522`로
일치했다. 전체 학습은 한 번 수행했으므로 전체 결과의 seed 간 변동성은 아직
측정하지 않았다.

## 검증 결과

최고 체크포인트는 epoch 5이다. 이후 네 epoch 동안 macro AUROC가 개선되지
않아 epoch 9에서 조기 종료했다.

| 클래스 | AUROC | Average precision |
|---|---:|---:|
| NORM | 0.94198 | 0.92352 |
| MI | 0.91505 | 0.81345 |
| STTC | 0.92914 | 0.78713 |
| CD | 0.92195 | 0.84781 |
| HYP | 0.90150 | 0.65590 |
| Macro | 0.92193 | 0.80556 |

검증 loss는 0.28138이었다. 이 수치는 한 번의 검증 폴드 평가 결과이며 최종
시험 성능이나 임상적 유효성을 뜻하지 않는다.

## 해석과 다음 검증

- HYP의 average precision이 다른 클래스보다 낮아 불균형과 오류 사례를
  우선 분석해야 한다.
- 현재 결과는 단일 seed이므로 반복 학습을 통한 변동성 추정이 필요하다.
- threshold 기반 민감도·특이도, 확률 보정, 신뢰구간은 아직 평가하지 않았다.
- 연령·성별 하위집단 및 신호 품질별 성능 차이를 아직 평가하지 않았다.
- 외부 데이터 검증과 의료기기 수준의 임상 검증은 수행하지 않았다.
- 시험 폴드는 평가 계획과 임계값을 검증 폴드에서 고정한 뒤 한 번만 사용한다.

## 잠긴 시험 평가

`docs/evaluation_protocol_v1.md`를 먼저 고정하고 시험 fold 10을 한 번
평가했다. 검증에서 전체 다섯 출력에 공통으로 적용할 temperature 1.08610과
클래스별 Youden J 임계값을 결정했다.

| 클래스 | AUROC | Average precision | 민감도 | 특이도 | Precision |
|---|---:|---:|---:|---:|---:|
| NORM | 0.93600 | 0.90896 | 0.90031 | 0.82008 | 0.80129 |
| MI | 0.90746 | 0.80008 | 0.77636 | 0.86194 | 0.65794 |
| STTC | 0.93369 | 0.83227 | 0.85221 | 0.86439 | 0.66667 |
| CD | 0.90662 | 0.83364 | 0.80040 | 0.88327 | 0.67174 |
| HYP | 0.89756 | 0.67790 | 0.80534 | 0.82911 | 0.39439 |
| Macro | 0.91627 | 0.81057 | 0.82693 | 0.85176 | 0.63841 |

- 시험 기록: 2,158건, 환자 1,877명
- macro AUROC 95% patient-cluster bootstrap 구간: 0.90871~0.92378
- macro average precision 95% 구간: 0.79269~0.82625
- 보정 전후 시험 NLL: 0.28636 → 0.28493
- 보정 전후 시험 15-bin macro ECE: 0.02759 → 0.02750
- `age=300`으로 비식별화된 32건은 연령 하위집단 비교에서 제외

Temperature scaling의 개선은 작았다. HYP는 민감도 0.80534를 얻는 대신
precision이 0.39439로 낮아 false positive 분석과 사용 목적에 맞춘 운영점
설계가 필요하다.

탐색적 하위집단 macro AUROC는 sex code 0/1에서 각각 0.92429/0.90777,
artifact 주석 있음/없음에서 0.90868/0.91856이었다. 이는 구성과 유병률이
다른 관찰 하위집단의 기술 통계이며 공정성이나 인과적 차이의 증거가 아니다.

## 사후 신뢰도 분석

Baseline v1을 동결한 뒤 오류와 신뢰도 분석을 수행했다.

- 기술 품질 점수의 artifact 주석 AUROC: 검증 0.5263, 시험 0.5568
- 기술 품질 점수의 any-label 오류 탐지 AUROC: 시험 0.5039
- 결정 경계 uncertainty의 any-label 오류 탐지 AUROC: 시험 0.7573
- 검증 80% 목표 cutoff의 시험 실제 coverage: 0.7743
- 해당 하위집단 Hamming 오류율: 0.1270, 전체는 0.1504
- 해당 하위집단 any-label 오류율: 0.4201, 전체는 0.4893

기술 품질 점수는 오류 탐지력이 없어 uncertainty와 결합하지 않았다. 선택적
판정 결과는 보류로 인해 구성 자체가 달라진 하위집단 성능이므로 모델의 분류
성능이 개선됐다고 해석하지 않는다.
